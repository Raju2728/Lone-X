LONE X - WINDOWS SETUP

1. Download Lone-X-Windows.zip on a Windows x64 PC.
2. Right-click the ZIP, choose Extract All, and select a folder you can write to.
3. Open the extracted Lone X folder and double-click Lone X.exe.
   Keep the resources folder and the other extracted files beside Lone X.exe.
4. On first launch, create your local account with an email address and a
   password of at least 8 characters. Sign-in lasts for three days on this PC.
5. Select Chat in the sidebar and send a message to Raju. The first response
   may take longer while the bundled model loads.

LOCAL AI

The ZIP includes Ollama's CPU runtime and the qwen2.5:0.5b model. Local chat
works offline after extraction and requires no separate installer or API key.
Chat history is stored on this PC and expires after 30 days.

OPTIONAL MODELS

Open the model picker beside Send in Chat. Select Qwen2.5 Coder 0.5B or
Gemma 3 1B and click Download if prompted. Internet is needed for the first
download. Afterward, both models run offline without an API key.

For a separate Ollama installation, start Ollama and run these commands
in PowerShell for the models you want:
  ollama pull qwen2.5:0.5b
  ollama pull qwen2.5-coder:0.5b
  ollama pull gemma3:1b
  ollama pull qwen3:4b-instruct
  ollama list

Use the in-app download button with the ZIP. The bundled runtime stores
its models separately from a standalone Ollama installation.

LOCAL AI USAGE LIMITS
Lone X allows 100,000 input and output tokens per five-hour window and
1,000,000 per seven-day window, shared across supported models on this
installation. Each timer starts with its first request and resets independently.
Usage survives app restarts. Open Limits in the side navigation to view
remaining usage and reset times. A running response may finish over the allowance;
new requests pause until both windows have capacity. Interrupted responses
use conservative estimates if Ollama does not return token counts.
These are Lone X limits; no OpenAI account or subscription is involved.

TROUBLESHOOTING

If Lone X does not start, extract the entire ZIP before opening the executable.
If chat reports that the bundled runtime cannot start, make sure the resources
folder is present, then close and reopen Lone X.

Email confirmation and password reset by email require SMTP setup.
Project help: https://github.com/Raju2728/Lone-X

CHECK FOR UPDATES

In Settings > Terminal, type LoneX -v to see the build label. Type
LoneX -Avail to check GitHub without downloading, or LoneX -update to
download a newer verified ZIP if one is available. Extract
an update to a new folder and open its Lone X.exe after closing the old app.

PC STORAGE, FILES AND APPLICATIONS

Settings > Storage & files reviews a folder selected through the Windows picker.
It shows free drive space and up to 30 largest files from a bounded scan.
You can approve moving a reviewed file to the Windows Recycle Bin. System and
Lone X files are protected. Refresh the scan after changes. Permission errors
are reported; Windows access controls still apply.

Use Projects to read UTF-8 text files, save edited copies, or review supported
in-place edits with backups. Settings > Software offers Node.js LTS, Git and
7-Zip through WinGet. Review the plan and publisher installer before proceeding.

UNINSTALL

In the app Terminal, run LoneX -uninstall to open the uninstaller. You can
also close Lone X and double-click Uninstall-LoneX.cmd in the extracted folder.
Review and confirm the exact folder shown. It removes that app copy and its
bundled Ollama runtime/models. Local accounts, chats and settings are kept.
To also erase Lone X local profiles, open PowerShell in the extracted folder:
  $lonexUninstaller = Join-Path (Get-Location) 'Uninstall-LoneX.ps1'
  Set-Location $env:TEMP
  powershell -NoProfile -ExecutionPolicy Bypass -File $lonexUninstaller -RemoveUserData
To preview removal without changing files, use:
  powershell -NoProfile -ExecutionPolicy Bypass -File .\Uninstall-LoneX.ps1 -WhatIf
Standalone Ollama, other installed tools, external projects and external
downloads are preserved. Anything you placed inside the app folder is removed
with that folder, so move personal files out first. Linked files/folders must
be removed manually before uninstalling. No administrator launch is required
unless Windows permissions on the chosen extraction folder require it.

CHAT AGENT

PC-WIDE ACCESS
In Chat, click PC-wide access and review the Windows confirmation. This
enables supported file tools across accessible Windows drives for the app
session. Use full paths, for example E:\Documents\Welcome.txt, or name
Desktop/Documents/Downloads. Agent mode and Qwen3 Instruct are selected.
Each file creation, edit, recycling request or project command still needs
your approval. The review shows the full destination path. Edits keep a
.lone-x-backups folder beside the affected file. Disconnect revokes access.
File tools block credential paths, linked paths, UNC/device paths and changes
to protected Windows/Lone X directories. Normal Windows permissions apply;
the app does not request administrator elevation. The 16 KB text-file and
per-turn action limits still apply. PC-wide is an access scope, not an
unrestricted shell or permanent background permission.

In Chat, click Choose agent folder and select a separate project folder.
Use Desktop selects your actual Windows Desktop after an access confirmation.
Direct prompts such as Create a new text file in Desktop and write
"Welcome to LoneX" in it also request Desktop access and enable Agent mode.
If the model is missing, download it when prompted, then send the prompt again.
This selects Qwen3 4B Instruct and enables Agent mode. Download the model
when prompted (about 2.5 GB); afterward it runs locally without an API key.
This model uses Apache 2.0: https://ollama.com/library/qwen3:4b-instruct
The model is downloaded on demand, not stored in the Git repository or ZIP.

Ask Raju to create or edit files in that folder. Review the full current and
proposed content, then approve or reject each change. Existing files must
be read before edits. Backups are kept in .lone-x-backups. Recycling also
requires approval. Disconnect revokes this session's selected folder.

Agent scope: approved folder creation, UTF-8 text files up to 16 KB, bounded directory listings, up
to 16 tool actions per turn, and approved npm tests or lockfile-based npm
dependency installs. Scripts run with your Windows permissions and can
access files/network beyond the folder, so inspect the command review.
Stop cancels further work; already approved changes remain and are reported.
Model performance and accuracy vary by PC. Verify generated code and tests.
